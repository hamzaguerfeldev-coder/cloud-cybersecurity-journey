# ☁️ Cloud & Cybersecurity Engineering Journey

> Intensive self-training path toward a **Cloud Engineer / DevSecOps Engineer** role, publicly documented with real hands-on labs, code, and concrete proof of skills.

**Pace:** 20h/week | **Estimated duration:** 10-12 months | **Method:** theory → hands-on lab → documentation → commit

---

## 🎯 Objective

Become job-ready for a Cloud Engineer / DevSecOps role by mastering:
- Linux administration and networking fundamentals
- Cloud architectures (AWS as primary focus, multi-cloud awareness)
- Infrastructure as Code (Terraform, Ansible)
- Containerization and orchestration (Docker, Kubernetes)
- Applied cybersecurity (IAM, cyber defense, SOC, DevSecOps)
- Emerging 2026 market topics (FinOps, AI security, platform engineering)

Every skill is validated through a **hands-on lab**, documented and version-controlled in this repo — not just passively followed courses.
