# ☁️ Cloud & Cybersecurity Engineering Journey

> Parcours d'auto-formation intensif vers un poste de **Cloud Engineer / DevSecOps Engineer**, documenté publiquement avec des travaux pratiques réels, du code, et des preuves concrètes de compétences.

**Rythme :** 20h/semaine | **Durée estimée :** 10-12 mois | **Méthode :** théorie → TP pratique → documentation → commit

---

## 🎯 Objectif

Devenir opérationnel sur un poste de Cloud Engineer / DevSecOps en maîtrisant :
- L'administration Linux et les bases réseau
- Les architectures cloud (AWS en priorité, notions multi-cloud)
- L'Infrastructure as Code (Terraform, Ansible)
- La conteneurisation et l'orchestration (Docker, Kubernetes)
- La cybersécurité appliquée (IAM, cyber défense, SOC, DevSecOps)
- Les sujets émergents du marché 2026 (FinOps, sécurité de l'IA, platform engineering)

Chaque compétence est validée par un **TP pratique**, documenté et versionné dans ce repo — pas seulement des cours suivis passivement.

## 💡 Pourquoi ce repo

Ce n'est pas une liste de cours suivis — c'est un **journal de bord technique** avec des preuves concrètes :
- Chaque module = un TP réel, pas juste de la théorie lue
- Chaque commit documente une étape de progression réelle
- L'objectif : arriver en entretien avec des exemples concrets à montrer, pas juste des certifications listées sur un CV
